2) Telefon:
   https://aykutmdd.github.io/dartcricket/remote.html

   Oyuncuları seç ve oyunu başlat.
   Telefon sadece kumanda olur, TV sadece skor ekranı.

FIREBASE KURULUMU (bir defalık)
1) https://console.firebase.google.com/ adresinden yeni proje oluştur.
2) Project Overview ekranında Web (</>) uygulaması ekle.
3) Sana verilen firebaseConfig nesnesindeki değerleri
   firebase-config-v6.js dosyasına yapıştır.
4) Build > Realtime Database > Create Database ile veritabanı oluştur.
5) İlk TEST için Rules bölümüne aşağıdakini koy:

{
  "rules": {
    ".read": true,
    ".write": true
  }
}
